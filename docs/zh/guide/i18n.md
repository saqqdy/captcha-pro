# 多语言

captcha-pro 内置中文（`zh-CN`）与英文（`en-US`）支持，默认自动检测浏览器语言。

## 全局语言

```javascript
import { SliderCaptcha, setLocale, getLocale, t } from '@captcha-pro/core'

// 全局设置语言
setLocale('en-US')

// 获取当前语言
console.log(getLocale()) // 'en-US'

// 获取翻译文本
console.log(t('slider.success')) // 'Verification passed'
```

## 组件级语言

在单个实例上覆盖全局语言：

```javascript
const captcha = new SliderCaptcha({
  el: '#captcha',
  locale: 'en-US' // 组件级别语言设置
})
```

## 自动检测

默认情况下，captcha-pro 自动检测浏览器语言。中文浏览器显示中文，其他显示英文。设置显式语言可覆盖自动检测。
