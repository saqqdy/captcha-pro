# 验证码类型

captcha-pro 提供四种验证码类型，均框架无关并共享一致的选项结构。

## 验证模式

所有类型均支持两种模式：

- 🎯 **前端模式** — 纯前端验证，无需后端（默认）
- 🌐 **后端模式** — 服务端验证与图片生成

## 滑动拼图验证码

随机形状（方形/三角形/梯形/五边形）与随机旋转的迷惑坑位的拼图验证。用户将滑块拖入缺口。

→ [滑动拼图选项与方法](/zh/components/slider)

## 点选文字验证码

200+ 中文词汇支持，每个词汇不含重复字，随机插入迷惑文字，提示图片防机器识别。

→ [点选文字选项与方法](/zh/components/click)

## 弹窗验证码

滑动或点选验证码的模态包装器，可由元素点击或编程式触发。

→ [弹窗验证码选项与方法](/zh/components/popup)

## 智能无感验证

基于风险评估的隐形验证，行为追踪与分析。仅在风险分数超过阈值时显示挑战。

→ [智能无感选项与方法](/zh/components/invisible)

## 安全

所有类型均支持共享的 `security` 选项（AES-GCM 加密 + 时间戳校验）与服务端验证的 `backendVerify` 选项。详见[进阶用法](/zh/guide/advanced-usage)。
