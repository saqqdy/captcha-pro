## SliderCaptcha Options

Complete configuration options for the slider captcha:

```typescript
interface SliderCaptchaOptions {
  // Container (required)
  el: string | HTMLElement

  // Images
  bgImage?: string       // Background image URL
  sliderImage?: string   // Slider image URL (optional, auto-generated by default)

  // Dimensions
  width?: number         // Container width, default 300
  height?: number        // Container height, default 170
  sliderWidth?: number   // Slider width, default 42
  sliderHeight?: number  // Slider height, default 42

  // Verification
  precision?: number     // Verification precision (px), default 5
  verifyMode?: 'frontend' | 'backend'  // Verification mode, default 'frontend'

  // Styling
  showRefresh?: boolean  // Show refresh button, default true
  className?: string     // Custom class name, default 'captcha-slider'

  // Backend verification
  backendVerify?: BackendVerifyOptions

  // Security
  security?: SecurityOptions

  // Internationalization
  locale?: 'zh-CN' | 'en-US'

  // Callbacks
  onSuccess?: () => void
  onFail?: () => void
  onRefresh?: () => void
}
```

### Example

```javascript
new SliderCaptcha({
  el: '#captcha',
  width: 300,
  height: 170,
  precision: 5,
  showRefresh: true,
  onSuccess: () => console.log('Passed!')
})
```

## PopupCaptcha Options

Complete configuration options for the popup captcha:

```typescript
interface PopupCaptchaOptions {
  // Trigger (required)
  trigger: string | HTMLElement  // Trigger element or selector

  // Captcha type
  type: 'slider' | 'click'  // default 'slider'

  // Captcha options
  captchaOptions?: SliderCaptchaOptions | ClickCaptchaOptions

  // Modal
  modal?: PopupModalOptions

  // Behavior
  autoClose?: boolean   // Auto-close on success, default true
  closeDelay?: number   // Close delay (ms), default 500

  // Callbacks
  onOpen?: () => void
  onClose?: () => void
  onSuccess?: () => void
  onFail?: () => void
}
```

### PopupModalOptions

```typescript
interface PopupModalOptions {
  title?: string          // Modal title
  maskClosable?: boolean  // Close on mask click, default true
  escClosable?: boolean   // Close on ESC, default true
  showClose?: boolean     // Show close button, default true
}
```

### Example

```javascript
new PopupCaptcha({
  trigger: '#submit-btn',
  type: 'slider',
  modal: {
    title: 'Security Verification',
    maskClosable: true
  },
  captchaOptions: {
    width: 300,
    height: 170
  },
  onSuccess: () => console.log('Passed!')
})
```

## InvisibleCaptcha Options

Complete configuration options for the invisible captcha:

```typescript
interface InvisibleCaptchaOptions {
  // Trigger (required)
  el: string | HTMLElement  // Trigger element or selector

  // Trigger event
  trigger?: 'click' | 'submit' | 'focus'  // default 'click'

  // Risk assessment
  riskAssessment?: RiskAssessmentOptions

  // Challenge type
  challengeType?: 'slider' | 'click'  // default 'slider'
  challengeOptions?: object  // Options for the challenge captcha

  // Callbacks
  onChallenge?: () => void  // Fired when a challenge is shown
  onSuccess?: () => void
  onFail?: () => void
}
```

### RiskAssessmentOptions

```typescript
interface RiskAssessmentOptions {
  threshold?: number  // Risk threshold (0-1), default 0.7
  behaviorCheck?: {
    minInteractionTime?: number  // Minimum interaction time (ms)
    trackAnalysis?: boolean      // Trajectory analysis
  }
}
```

### Example

```javascript
new InvisibleCaptcha({
  el: '#submit-btn',
  trigger: 'click',
  riskAssessment: {
    threshold: 0.7,
    behaviorCheck: {
      minInteractionTime: 500,
      trackAnalysis: true
    }
  },
  challengeType: 'slider',
  onChallenge: () => console.log('Showing challenge...'),
  onSuccess: () => form.submit()
})
```

## Common Options

The following options apply to all captcha types:

### BackendVerifyOptions

```typescript
interface BackendVerifyOptions {
  getCaptcha: string | Function  // URL or function to fetch the captcha
  verify: string | Function      // URL or function to verify
  headers?: object               // Request headers
  timeout?: number               // Timeout (ms), default 10000
}
```

**Example:**

```javascript
backendVerify: {
  getCaptcha: '/api/captcha?type=slider',
  verify: '/api/captcha/verify',
  headers: {
    'X-Requested-With': 'XMLHttpRequest'
  },
  timeout: 10000
}
```

### SecurityOptions

```typescript
interface SecurityOptions {
  secretKey?: string         // AES-GCM encryption key
  enableSign?: boolean       // Enable signing, default false
  timestampTolerance?: number // Timestamp tolerance (ms), default 60000
}
```

**Example:**

```javascript
security: {
  secretKey: 'your-secret-key',
  enableSign: true,
  timestampTolerance: 60000
}
```
